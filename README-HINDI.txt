MY FINANCE PRO — FREE PWA PROJECT

Files:
- index.html: app UI and finance tracker
- manifest.webmanifest: installable app metadata
- sw.js: offline cache
- icon.svg: app icon

FREE Android setup:
1. Upload these files to a public GitHub repository.
2. In GitHub: Settings > Pages > Deploy from branch > main > / (root) > Save.
3. Wait for the Pages URL to become available.
4. Open that HTTPS URL in Chrome on Android.
5. Chrome menu (⋮) > Install app / Add to Home screen.
6. Open MY FINANCE PRO from your home screen.

Important:
- This is a Progressive Web App (PWA), not a Play Store APK.
- Data is stored locally in the browser on that device. It does not sync automatically across devices.
- Use Reports & backup to download JSON backups regularly.
- Do not enter OTPs, PINs, passwords, CVV or full card details.
- No bank login is connected; account and investment values are entered manually.
- Google Sheets / GitHub Pages are optional free services; internet is needed for first install and hosted updates.
